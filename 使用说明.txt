【一、文件都是干什么的】
  index.html        主页(五个板块都在这里)
  reflection.html   反思独立页
  moments.html      重要时刻独立页
  gallery.html      照片独立页
  likes.html        她喜欢的独立页
  data.js           ★ 所有内容数据都在这一个文件里(最重要)
  style.css         全站样式(颜色、字体、间距)
  photos/elena/     她的照片(1.jpg、2.jpg…不带前导零)
  photos/both/      两个人的合照
  cats/             两侧的小猫装饰图
  使用说明.txt      本文件

【二、改内容 —— 只需动 data.js】
用记事本或 VS Code 打开 data.js,从上到下五个区:

① 纪念日
   var anniversary = '2026-06-18';
   改成你们的日期,主页自动显示"在一起第 N 天"。
   留空 '' 则不显示。

② 反思墙(每次惹她生气后的反思)
   每一条长这样:
   { date: '2026.08.18', title: '标题', text: '正文内容' }
   加新反思:复制一整条(包括大括号和逗号),粘到上一行后面。
   格式要求:每条以 { 开头 } 结尾,条与条之间用英文逗号 ,
   分号 ; 和冒号 : 也用英文的。中文标点只用在文字内容里。

③ 重要时刻
   每一条: { date: '日期', title: '标题', note: '说明文字' }
   加新时刻:同上,复制一条改内容。

④ 照片墙(分两组)
   photosElena = 她一个人的照片路径,每个 'photos/elena/XX.jpg'
   photosBoth  = 两个人的合照路径,每个 'photos/both/XX.jpg'
   新照片步骤:
   1) 把图片放进对应文件夹(elena 或 both),命名 1.jpg、2.jpg…
      (注意:不带前导零,不能叫 01.jpg;格式 jpg 或 png 都行,
       但数组里写的扩展名要和文件一致)
   2) 在数组里加一个 'photos/elena/新名字.jpg' ,用英文逗号隔开
   主页每组的展示数量,改下面两个数字:
   var homeElenaCount = 6;  // 主页显示几张她的
   var homeBothCount = 6;   // 主页显示几张合照
   想看全部,点主页照片区右上角"更多 →"。

⑤ 她喜欢的
   每一条: { cat: '类别', txt: '内容' }
   例:{ cat: '歌', txt: '她爱听的歌名' }
   类别可以自由加,比如 '电影'、'地方'、'花'。

【三、改文字 —— 动对应的 html 文件】
   - 网站名、导航栏:每个 html 顶部 <header> 里的文字
   - 板块大标题(反思/重要时刻/…):各 html 里 <h1> 或 <h2> 标签中间
   - 副标题:对应 <p> 标签中间
   - 页脚"写给Elena":每个 html 最下面 <footer> 里
   注意:只改标签中间的文字,别动 <> 尖括号和标签名。

【四、改样式 —— style.css】
   文件最顶部有颜色变量,改这里全站一起变:
   --bg        页面背景色(现在是米白)
   --ink       正文文字色(深棕)
   --accent    点缀色(陶土红,标题小字、按钮)
   --accent-soft 点缀色浅底
   想换主题色,只改 --accent 一行即可。
   颜色写法:#c0795f 这种六位十六进制。

【五、小提示】
   - 每张照片最好 1MB 以内,太大网页会卡。
   - 手机和电脑都能看,双击 index.html 就行。
   - 改完保存,浏览器按 Ctrl+F5 强制刷新看效果。
   - 想加新板块(比如"给她的话")?找 Jarvis 帮你加。
